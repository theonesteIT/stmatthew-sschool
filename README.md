# ST Matthew's School — Static HTML Site

Open `index.html` in a browser, or serve this folder with any static file server.

## Pages
- index.html — Home
- about.html — About
- gallery.html — Gallery
- events.html — Events
- contact.html — Contact

## Assets
Images are in `assets/` (gallery photos in `assets/gallery/`).

## Regenerate
From the frontend folder run: `npm run export:html`
